# Day 1 – ReCraft AI Customer Support Assistant

## Project Overview
ReCraft AI is an AI-powered customer support assistant developed for a creative recycling and upcycling business.

The chatbot helps customers understand products, customization options, and ordering procedures through simple and friendly conversations.

## Objectives
- Build an AI-powered customer support chatbot.
- Understand how Large Language Models (LLMs) work.
- Connect an LLM using the Groq API.
- Use LangChain to interact with the language model.
- Create a customized AI assistant using system instructions.

## Technologies Used
- Python
- Google Colab
- Groq API
- LangChain
- LLM – GPT-OSS-120B

## Features
1. Answers customer questions about ReCraft products.
2. Provides information about recycled decorative items.
3. Explains reusable bags made from old clothes.
4. Suggests customization ideas.
5. Guides customers through the ordering process.
6. Provides friendly and simple responses.

## Implementation
1. Installed and imported the required Python libraries.
2. Configured the Groq API key using Google Colab Secrets.
3. Initialized the ChatGroq language model.
4. Created a system prompt containing business information and chatbot rules.
5. Developed an `ask()` function to process customer questions.
6. Tested the chatbot with different customer queries.

## Example
**Customer:** What products do you sell?

**ReCraft AI:** We offer decorative pieces, reusable bags, planters, and customized upcycling products.

## Learning Outcomes
- Learned how to connect an LLM using an API.
- Understood basic LangChain integration.
- Learned how system prompts control chatbot behavior.
- Implemented a basic AI customer support assistant.

## Security
The Groq API key is stored securely using Google Colab Secrets and is not included in the source code.

## Conclusion
Successfully developed and tested a basic AI-powered customer support assistant for ReCraft using Python, LangChain, and Groq.
