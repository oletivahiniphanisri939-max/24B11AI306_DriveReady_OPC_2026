# Day 2 – ReCraft AI Business Assistant

## Project Overview
ReCraft AI is a Smart Waste-to-Product Business Assistant developed as part of the AI Agents Workshop – Level 1.

## Concepts Implemented
1. Messages and roles
2. System prompts
3. Few-shot prompting
4. JSON output
5. Chat memory
6. Python dictionaries
7. Functions and type hints
8. Decorators
9. Exception handling

## Technologies
- Python
- Google Colab
- JSON

## Features
- Waste-to-product suggestions
- Product information lookup
- Customer data extraction
- Chat history demonstration
- Error handling

## Learning Outcome
Learned the fundamentals of prompts, memory and Python concepts required to build AI agents.
